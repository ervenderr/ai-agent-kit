# Ecosystem

## Discovery (read, do not mass-install)
- [hesreallyhim/awesome-claude-code](https://github.com/hesreallyhim/awesome-claude-code)
- [VoltAgent/awesome-claude-code-subagents](https://github.com/VoltAgent/awesome-claude-code-subagents)

## Reference agent templates to compare against
- [vstorm-co/full-stack-ai-agent-template](https://github.com/vstorm-co/full-stack-ai-agent-template): full-stack, framework-based.
- [wassim249/fastapi-langgraph-agent-production-ready-template](https://github.com/wassim249/fastapi-langgraph-agent-production-ready-template): FastAPI + LangGraph.

This kit is the small end of the range: plain SDK loop, one page UI, evals and guardrails included.

## Evals and tooling
- [promptfoo](https://github.com/promptfoo/promptfoo): config-driven evals, `llm-rubric` judged checks, red-teaming.
- [DeepEval](https://github.com/confident-ai/deepeval): pytest-style LLM metrics.
- `/claude-api build-eval` and `/claude-api hillclimb`: bundled, for Claude-powered apps.

## Claude Code built-ins (do not rebuild)
`/doctor`, `/doctor prompt-audit`, `/skill-doctor`, `/verify`, `/code-review`, `/simplify`.
